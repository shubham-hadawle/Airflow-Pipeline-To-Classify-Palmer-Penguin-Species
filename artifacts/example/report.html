How to interpret this run

Logistic regression and a most-frequent-species baseline share the same stratified 25% holdout (seed 17). Preprocessing is fitted only on training birds. The separate Airflow quality-gate task requires macro F1 ≥ 0.90 and an improvement ≥ 0.10 over the baseline; its decision is saved in release.json.

This small historical sample is a teaching dataset. The random holdout does not establish performance on new colonies, future years, or juvenile birds. No hyperparameters were selected using this holdout.
